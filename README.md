# Cadence

일한 시간이 쌓이면 메뉴바 캐릭터가 자라는 맥·윈도우 앱.

**내려받기 · 사용법 → https://kwongyumin.github.io/cadence-app/**

## 이 저장소에 있는 것

배포물만 있습니다 — 랜딩 페이지(`index.html`)와 [Releases](../../releases)의 설치 파일.
앱 소스는 여기에 없습니다.

| 파일 | 대상 |
|---|---|
| `Cadence-0.1.0-x64-setup.exe` | Windows 10 이상 (대부분의 PC) |
| `Cadence-0.1.0-arm64-setup.exe` | ARM Windows (Snapdragon 등) |
| `Cadence-0.1.0-arm64.dmg` | Apple Silicon 맥 |
| `Cadence-0.1.0.dmg` | 인텔 맥 |

## 설치할 때 경고가 뜨면

개발자 서명을 아직 받지 않아 생기는 절차입니다. 한 번만 통과시키면 다시 뜨지 않습니다.

- **macOS** `확인되지 않은 개발자` → 파인더에서 앱을 **우클릭 → 열기**
- **Windows** `PC를 보호했습니다` → **추가 정보 → 실행**
